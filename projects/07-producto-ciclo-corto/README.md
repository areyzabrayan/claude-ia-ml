# 07 · Producto en ciclo corto

## Objetivo
Cerrar el círculo: tomar piezas de los proyectos anteriores (RAG, agentes, testing) y entregar
un producto pequeño pero completo, documentando el ciclo de entrega de principio a fin.

## Qué vas a aprender
- Definir un alcance chico y realista (MVP) en vez de sobre-diseñar.
- Ciclo completo: spec corta → construir → probar → lanzar → recibir feedback → iterar.
- Documentar decisiones y trade-offs para que el proyecto sea sostenible sin ti al lado.
- Medir el propio ciclo de entrega (cuánto tardó cada etapa) como evidencia de velocidad.

## Entregable
- Un producto pequeño funcionando end-to-end (ej. una app con RAG sobre un dominio específico,
  o un asistente con agente + interfaz simple).
- `SPEC.md` corto escrito ANTES de empezar a construir (alcance, no-alcance, criterio de éxito).
- `CHANGELOG.md` o bitácora con las iteraciones reales (qué cambió en cada ciclo y por qué).

## Criterios de "hecho"
- [ ] Producto usable de punta a punta (no solo scripts sueltos).
- [ ] Tests cubriendo el camino feliz y al menos un caso límite.
- [ ] Bitácora de al menos 2 ciclos de iteración documentados con fecha y duración.
